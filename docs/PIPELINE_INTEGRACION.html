C. Renaming del stack integrado (pendiente)

Propuestas: CAVA (Consumer-Adaptive Video Architecture, sugerido) · CERTISUM (certificación como distintivo) · FRAMECAST (frame-awareness → multi-formato). El rename toca paquete, configs y docs — script trivial post-decisión.
